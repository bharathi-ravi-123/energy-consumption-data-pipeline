# ⚡ Energy Consumption Data Engineering Pipeline

## 📌 Project Overview

An end-to-end data engineering pipeline for processing and analyzing energy consumption data using modern cloud and data engineering technologies.

The project integrates Azure, Databricks, PySpark, Delta Lake, dbt, Apache Airflow, and SQL to build a scalable and automated data pipeline.

## 🛠️ Technologies Used

* Azure
* Databricks
* PySpark
* Delta Lake
* dbt
* Apache Airflow
* SQL
* Python

## 🏗️ Project Architecture

The pipeline follows a layered data engineering architecture with data ingestion, transformation, data quality validation, orchestration, and analytics.

## 🚧 Project Status

This project is currently under development. More pipeline components, transformations, tests, documentation, and architecture details will be added progressively.
